# Circuit Connections

## ESP32 Pin Connections

| Component | ESP32 Pin |
|---|---|
| MQ-2 Analog | GPIO 34 |
| MQ-5 Analog | GPIO 35 |
| DHT11 Data | GPIO 2 |
| LCD SDA | GPIO 21 |
| LCD SCL | GPIO 22 |
| Buzzer | GPIO 18 |
| Red LED | GPIO 19 |
| Green LED | GPIO 23 |

## Power Connections
- Connect sensor modules to suitable supply voltage.
- Connect all circuit grounds together.
- Check voltage compatibility before connecting ESP32 pins.

## Note
MQ sensor readings require warm-up and calibration.
