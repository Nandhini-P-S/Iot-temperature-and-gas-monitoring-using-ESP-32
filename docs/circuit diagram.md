# Circuit Diagram

## ESP32 Sensor Connections

| Component | ESP32 Pin |
|---|---|
| MQ-2 | GPIO 34 |
| MQ-5 | GPIO 35 |
| DHT11 | GPIO 2 |
| LCD SDA | GPIO 21 |
| LCD SCL | GPIO 22 |
| Buzzer | GPIO 18 |
| Red LED | GPIO 19 |
| Green LED | GPIO 23 |

## Circuit Description

ESP32 acts as the main controller.
Gas sensors monitor gas-related readings.
DHT11 measures temperature and humidity.
LCD displays the sensor information.
LEDs and buzzer provide alerts.
