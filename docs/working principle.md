# Working Principle

1. MQ-2 monitors gas and smoke-related sensor readings.
2. MQ-5 monitors LPG-related sensor readings.
3. DHT11 measures temperature and humidity.
4. ESP32 collects and processes sensor readings.
5. LCD displays the monitoring status.
6. Buzzer and LEDs provide warning indications
   when the configured threshold is crossed.

## Controller
ESP32 Development Board

## Programming Language
Arduino C/C++
